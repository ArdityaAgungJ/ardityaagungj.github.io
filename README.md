# ardityaagungj.github.io

Personal portfolio of **Arditya Agung Jaya Pratama** — Full Stack Developer.

Plain static site (HTML + CSS + a little JS), no build step. English / Bahasa Indonesia toggle.

- `index.html` — content (English)
- `script.js` — Indonesian translations + language toggle
- `style.css` — styles (auto light/dark)

## Deploy

Repo Settings → Pages → *Deploy from a branch* → pick the branch and `/ (root)`.
Site will be live at https://ardityaagungj.github.io
